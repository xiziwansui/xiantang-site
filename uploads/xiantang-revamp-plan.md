# 禧安堂 xiantang.life — 网站改版完整规划

> 文档目的：作为输入交给 Claude design（或任何设计师），驱动一次完整的视觉与体验改版。
> 当前域名：https://www.xiantang.life/
> 当前技术栈：Webflow（保留）
> 改版周期目标：4–6 周（设计 2 周 + 落地 2 周 + 内容/i18n 1–2 周）

---

## 1. 品牌与战略 Brief

### 1.1 品牌一句话定位

> **禧安堂是安妍老师的命理之家 — 用紫微斗数、八字、风水，陪你看清当下，安顿未来。**

中文一句话（备选）：
- 「读懂命，才能安心生活」
- 「在快速的世界里，给你一个慢下来看自己的地方」
- 「中式智慧，现代语境 — 让命理重新被认真对待」

### 1.2 品牌支柱（Brand Pillars）

| 支柱 | 含义 | 在网站上的表现 |
|---|---|---|
| **专业可信** | 安妍老师的师承、方法论、案例都经得起推敲 | 关于页厚度、案例与见证、媒体出现、明确的方法论描述 |
| **精神疗愈** | 命理不是预测命运，是帮人看见自己、安顿当下 | 文案的温度、留白、视觉的暖意、慢节奏动效 |
| **现代审美** | 不古风、不仙气、不水晶博主感 | 编辑式版式、当代字体、自然光摄影 |
| **可亲近** | 安妍老师不是高高在上的"大师"，是陪你看的人 | 第一人称文案、真实人像、WhatsApp/微信直接联系 |

### 1.3 受众

**主要受众 A：潜在咨询客户**
- 30–55 岁，主要为女性（命理咨询客群偏女性，但不要把男性排除）
- 处于人生抉择期：择偶/婚姻、转职、创业、买房、孩子教育
- 已经对命理有基本好感，但被市面上「江湖气」「玄学博主」劝退过
- 决策路径：浏览网站 → 看安妍老师本人 → 看案例 → 加微信/WhatsApp 预约
- **网站需要解决的核心疑问**：「她靠不靠谱？」「我的问题适合哪个服务？」「价格大概多少？」「怎么开始？」

**主要受众 B：学员与社群粉丝**
- 已经认识安妍老师（来自 IG/FB/YouTube/活动）
- 想要更系统地学习命理
- 关心：新课程发布、安妍老师的最新观点、线下活动信息
- **网站需要解决的核心疑问**：「最近她在讲什么？」「下一期课什么时候开？」「能不能见到她本人？」

### 1.4 语气（Tone of Voice）

**是这样的：**
- 第一人称（「我」/「我们」），把安妍老师当成在跟你说话的人
- 短句、有呼吸感、不堆术语
- 自信但不傲慢；温暖但不甜腻
- 在专业话题上敢用专业词，但每个专业词都顺手解释一句

**不是这样的：**
- ❌ 「老师慈悲为怀」「上师开示」式的过度神圣化
- ❌ 「天机不可泄露」式的故作神秘
- ❌ 「这周双子座要小心了！」式的速食占星语气
- ❌ 全是「能量」「频率」「振动」这类没有具体含义的词

**示例对照：**

| 不要 | 要 |
|---|---|
| 命由天定，运由己生，老师将为您指点迷津 | 命盘里有结构，运势里有起伏 — 我帮你看清楚，怎么走由你定 |
| 紫微斗数博大精深，源远流长 | 紫微斗数是一套很好用的看人和看时机的工具，下面我用三段把它讲明白 |
| 添加微信，开启您的命运之旅 | 想聊聊？加我微信或 WhatsApp，第一次咨询前我们先 10 分钟视频，看看是不是合适 |

### 1.5 改版核心目标（按优先级）

1. **可信度与品质感升级** — 让第一次访问的人在 5 秒内觉得「这是专业的、可信赖的、值得继续看的」
2. **三个服务的清晰转化路径** — 取名 / 风水 / 论命 三个服务必须在首页就能看到、能直接预约
3. **课程内容的持续运营能力** — 安妍老师课程要能频繁更新，且发布动作不依赖开发
4. **首页 Live Gallery** — 线下活动 + 最新课程海报实时更新，让回访的粉丝总有新鲜感
5. **双语支持** — 简体中文为主，英文版作为国际受众入口
6. **社媒生态打通** — 网站作为内容资产中心，IG/FB/LinkedIn/YouTube 作为分发触点
7. **性能与移动端** — 移动端体验 ≥ 桌面端；首屏加载 < 2.5s；Core Web Vitals 全绿

## 2. 视觉与动效方向：「温暖现代灵性」

> 这一章是给 Claude design / 设计师的核心输入。

### 2.1 风格定调一句话

> **像一本当代灵性疗愈刊物，不像一个玄学网站。**

参照系（不是直接抄，是定调子）：

- **观夏（To Summer）** — 极简但有东方温度；克制的留白与摄影
- **闻献 DOCUMENTS** — 高级买手店的版式胆量，黑白与暖色的克制对比
- **Aesop** — 严肃可信的产品语境，文字优先
- **The Pattern / Sanctuary（占星 app）** — 当代灵性品牌的视觉语言，但更克制
- **Kinfolk / Cereal magazine** — 编辑式版式与自然光摄影
- **NOT** Co-Star（太冷、太几何、太美式）
- **NOT** 国内任何「水墨星空玄学博主」风
- **NOT** 任何中国风纹样、八卦图、太极图、毛笔字、烫金祥云

### 2.2 配色系统

主色（任选其一作为品牌主色，建议 **Terracotta 暖陶土** 作为主导）：

| 名称 | 色值（建议） | 用途 |
|---|---|---|
| **Terracotta 暖陶土** | `#C2603F` | 品牌主色 / 关键 CTA / 强调 |
| **Cream 杏仁奶油** | `#F5EFE6` | 主背景 / 大面积底色 |
| **Sage 鼠尾草绿** | `#8A9A82` | 次要色 / 静态卡片 / 标签 |
| **Plum Ink 深紫梅** | `#3B2A35` | 正文文字 / 深色区块 |
| **Honey Gold 蜂蜜金** | `#C99A3F` | 极少量点缀 / icon / 分隔线 |

辅助：
- 中性灰阶 `#1A1416 / #4A4045 / #8A7F84 / #D9CFC4` 用于次级文字与边线
- 纯白 `#FFFFFF` 不用作主背景；要用就用奶油白

**配色规则：**
- 任何一屏不超过 3 个主色 + 1 个点缀色
- Terracotta 与 Plum Ink 形成主对比；Sage 与 Cream 形成静态层
- Honey Gold 仅用于 hover 高亮、icon 强调、分隔细线 — 永不大面积使用
- 暗色模式：以 Plum Ink 为底，Cream 反白，Terracotta 提亮，Sage 退后

### 2.3 字体系统

**中文（简体）：**
- **标题字体（Display）** — 思源宋体 Heavy / 方正悠宋（用于大字编辑感的 hero 标题、章节标题）
- **正文字体（Body）** — 苹方 Regular / Misans Regular / 思源黑体 Regular（用于正文、UI、卡片）
- **强调字体（Accent）** — 思源宋体 Medium 斜体（用于引述、重要短句）

**英文：**
- **Display** — GT Alpina / PP Editorial New / Söhne Mono（标题与编辑式排版）
- **Body** — Söhne Regular / Inter / Outfit（正文）
- **Accent** — GT Alpina Italic（引述）

**字号与层级（基于 1280px 宽度桌面端）：**

| 层级 | 用途 | 建议字号 | 行高 |
|---|---|---|---|
| H0 Hero | 首屏大字 | 80–120px | 1.05 |
| H1 | 页面主标 | 56–72px | 1.1 |
| H2 | 章节标 | 36–48px | 1.2 |
| H3 | 子标题 | 24–28px | 1.3 |
| Body L | 正文加大 | 18–20px | 1.6 |
| Body | 正文 | 16px | 1.7 |
| Caption | 注释 | 13–14px | 1.5 |

移动端等比缩放，但 Hero 字号不低于 48px（保持「敢用大字」的胆量）。

**排版规则：**
- 中文字间距 `letter-spacing: 0.02em`，标题略紧 `0.01em`
- 段落最大宽度 `680px`，保证一行 32–40 字以内的可读宽度
- 中英混排时英文用 sans，中文用宋体 — 形成自然反差

### 2.4 图像与摄影方向

**核心视觉资产（要新拍/补拍）：**
1. **安妍老师人像** — 自然光、温暖、可亲近的工作环境（书桌前、点着蜡烛、有植物）。建议 3 套：正式半身（关于页 hero）、生活化全身（首页备选）、工作中纪实（咨询中、教学中）
2. **手部细节** — 翻命盘、写字、点蜡烛、捧茶杯（用于穿插，强化精神疗愈感）
3. **空间** — 工作室或线下活动空间，自然光，米色与陶土色调
4. **线下活动纪实** — 课程现场、学员合影、活动布置（首页 Gallery 用）

**摄影风格关键词：**
自然光 / 暖色调 / 浅景深 / 真实纪实 / 安静的瞬间 / 留白 / 温暖材质（亚麻、纸、陶器、木）

**避坑：**
- ❌ 星空 / 星座 / 宇宙 stock 图
- ❌ 命盘示意图作为装饰
- ❌ 任何 3D 渲染的水晶、塔罗、神秘符号
- ❌ 影楼感强的人像（精修过度、姿势僵硬）
- ❌ 过度滤镜（HDR、高饱和、暗角）

### 2.5 几何与图形语言

- **形状** — 圆角柔和（卡片圆角 12–24px，按钮圆角 8–12px）；偶尔用大圆形作为版式锚点
- **线条** — 极细 1px 分隔线（用 Honey Gold 或 Sage 50% 透明度），不用粗线
- **图标** — 线性图标，2px stroke，圆角端点；用 Lucide / Phosphor / 自定义同风格
- **不要** — 卦象图、星座符号、几何水晶、神秘学符号作为装饰

### 2.6 动效原则

> 关键词：**呼吸、缓慢、有重量。**

- **进场** — 元素 fade + slight rise（8–16px 上移），缓动 `cubic-bezier(0.22, 1, 0.36, 1)`，时长 600–900ms
- **滚动** — 章节切换允许 subtle parallax（≤ 10% 移动差），不要狂热视差
- **悬停** — 颜色与微缩放（≤ 1.02），时长 250ms，缓动温和
- **首页 Hero** — 允许一个慢速循环动效（如安妍老师人像周边的光斑 / 烛光呼吸），但只能有一个，不要堆动效
- **页面切换** — 整页淡入淡出 400ms，不要花哨切换
- **禁止** — 弹跳、抖动、快速旋转、突然放大、3D 翻转、cursor 跟随特效（除非极克制）

### 2.7 设计原则备忘（给设计师 / Claude design 的 Do/Don't）

**DO**
- 大字大留白
- 文字优先，图像辅助
- 一屏只讲一件事
- 用版式做层级，不靠颜色喧哗
- 把安妍老师本人当作品牌最重要的资产

**DON'T**
- 不用任何中国传统纹样
- 不用毛笔字、书法字、古风装饰字体
- 不用紫色星空、宇宙背景
- 不用八卦、太极、五行符号作为视觉装饰（但作为内容图示在文章里 OK）
- 不堆叠多种渐变与阴影
- 不要 emoji 作为装饰
- 不要 hover 时整张卡片做戏剧性变形

## 4. 各页面内容大纲

### 4.1 首页 Home

**目标：** 5 秒内让访客知道这是谁、做什么、能解决什么；30 秒内引导到三个转化入口（预约 / 看课 / 订阅）。

**模块顺序：**

1. **Hero** — 一句强陈述（如「读懂命，才能安心生活。」）+ 安妍老师人像（不是 logo，是人）+ 主 CTA「预约咨询」+ 副 CTA「看课程」
2. **三个服务模块（核心转化区）** — 「取名 / 风水 / 论命」三栏并列卡片，每张卡片：图标 / 标题 / 一句话定义 / 「了解 →」+ 总 CTA「直接预约安妍老师 → WhatsApp / 微信」
3. **Live Gallery** — CMS 驱动的横向滚动或 masonry 布局，混合展示「最新活动现场 + 最新课程海报」，每张图可点击进入对应详情。**这是首页最有「在动」的部分，每次访问都有新鲜感。**
4. **安妍老师简介** — 一段话 + 一张工作中的照片 + 「读她的故事 →」链接关于页
5. **课程入口** — 两栏：左「大耕老师在线课程」+ 右「安妍老师课程」，每栏 1 个精选课卡片 + 「看全部 →」
6. **精选文章 / 节气札记** — 3 篇最新文章，编辑式版式（不是商品卡片）
7. **学员与客户见证** — 3–5 条精选评价，带照片或匿名首字母 + 服务/课程标签
8. **Newsletter + 社交关注** — 订阅框 + 「关注 IG / FB / YouTube」入口
9. **Footer**

**Live Gallery 设计要点（重要）：**
- CMS Collection: `gallery_items`，字段 `image / title / description / type(event|course_poster|other) / link / date / pinned_to_home(bool) / order`
- 首页只显示 `pinned_to_home = true` 的条目，按 `order` 或 `date` 排序
- 视觉上：保留摄影/海报本身的质感，不加重边框；hover 显示标题与日期
- 移动端：横向滚动 snap，每屏 1.2 张

### 4.2 关于 About

**目标：** 让访客认识安妍老师本人，建立深度信任。

**模块顺序：**

1. **Hero 人像 + 一段开场** — 「我是安妍。我把命理当成一门可以好好聊的语言。」
2. **她的故事** — 长文形式（800–1200 字），分 3–4 段：缘起、师承、方法论的形成、为什么开禧安堂
3. **她的方法论** — 3–4 个关键词卡片（如「结构看人」「时机看运」「环境看场」「对话看心」），每个一段释义
4. **师承与训练** — 师从何人、学过哪些体系、关键时间线
5. **媒体出现 / 推荐人**（如有）— logo 墙或引用墙
6. **CTA** — 「想跟我聊聊？预约咨询 →」

### 4.3 命理服务 Services

**总服务页面结构：**
- Hero：「我提供三种服务：取名、风水、论命。每一种都是为了帮你把当下的某个具体问题，看清楚。」
- 三栏服务卡片，每个进入子页面
- 通用 FAQ（咨询前你可能想知道的 5–7 个问题）
- 联系入口

**单个服务页结构（每个服务都是同一个模板）：**

| 模块 | 内容 |
|---|---|
| Hero | 服务名 + 一句话定位 + 服务时长与形式 + 价格区间 + 主 CTA |
| 这是给谁的 | 3–4 个「如果你正在……」的具体情境 |
| 我会怎么做 | 流程步骤（咨询前 → 当面/视频咨询 → 后续支持），每步 1–2 句 |
| 包含什么 | 交付清单（如：1 小时一对一、命盘解读 PDF、3 天内文字总结、1 次后续追问） |
| 案例（脱敏） | 1–2 个真实案例摘录，匿名 |
| 常见问题 | 该服务相关的 4–6 个 FAQ |
| 价格与预约 | 价格、时长、预约方式（WhatsApp + 微信二维码） |
| 相关阅读 | 链接到该主题下的文章 |

**取名 / 风水 / 论命 三个服务的差异化要点：**

- **论命** — 强调「看清当下结构 + 三年内的关键时机」，主要工具紫微斗数 + 八字。客单价中等，是入门服务。
- **取名** — 强调「孩子取名 / 公司取名 / 改名」，配合八字与字音字义。客单价较低但流程长。
- **风水** — 强调「家居 / 办公空间」，到访或视频堪舆。客单价最高，需要更多前期沟通。

### 4.4 课程 Courses

**总课程页结构：**
- Hero：「禧安堂课程 — 跟着两位老师，把命理学到能用。」
- 两个区块：大耕老师课程 / 安妍老师课程（视觉上区分，但风格一致）
- 每个区块下是该老师的课程网格

**单课程页结构：**

| 模块 | 内容 |
|---|---|
| Hero | 课程名 + 副标 + 讲师 + 形式（在线/线下/混合）+ 时长 + 开课时间 + 价格 + 主 CTA「报名 / 联系」 |
| 课程封面/海报 | 大图 |
| 这门课讲什么 | 2–3 段说明 |
| 你会学到 | 3–6 条 outcomes |
| 课程大纲 | 章节列表，每章 1 句概述 |
| 适合谁 | 对象、前置知识 |
| 讲师介绍 | 带链接到讲师页 |
| 学员评价 | 3–5 条 |
| 报名信息 | 时间、地点、价格、报名方式（WhatsApp / 微信 / 报名表） |
| FAQ | 课程特定 FAQ |

### 4.5 文章 Journal

**列表页结构：**

### 5.2 多语言策略

**方案：Webflow Localization（官方功能）**

- 默认 Locale：简体中文（zh-CN）
- 第二 Locale：英文（en）
- 每个 CMS 条目都有两个语言版本，分别填写
- URL 结构：`xiantang.life/services/divination`（中文）/ `xiantang.life/en/services/divination`（英文）
- 顶部导航语言切换器：中 / EN
- 浏览器语言自动跳转（首次访问）+ 记住用户选择

**翻译工作流：**
- 中文先行：所有内容先以中文产出与发布
- 英文版：用 Claude 把每个条目翻译为英文，安妍老师审一遍 → 在 Webflow 后台粘贴对应字段
- 不强求 100% 同步：英文版可以是中文版的子集（例如先翻关于、服务、5 篇核心文章），后续滚动补齐

## 6. 内容运营与社媒分发

### 6.1 内容生产工作流（推荐方案 B：Claude + Webflow MCP + 人工社媒）

**典型流程（以一篇文章为例）：**

1. **构思** — 安妍老师跟 Claude 对话，确定主题与角度
2. **起草** — Claude 起初稿（中文 1500–2500 字），安妍老师改
3. **定稿后**，让 Claude 一次产出：
   - 网站文章（中文最终版 + 英文翻译版）
   - Instagram caption（150–200 字 + 3–5 个 hashtag）
   - Facebook 文案（300–500 字，带链接预览友好的开头）
   - LinkedIn 摘要（专业语气版本，300–400 字）
   - YouTube Shorts 脚本（如果配合视频）
4. **Claude 通过 Webflow MCP 直接发布到网站**
5. **安妍老师/助理用 Meta Business Suite 一次发 IG + FB**，再去 LinkedIn 与 YouTube 补一遍
6. **链接回流到网站文章**

总耗时：原本 3–4 小时，现在 1–1.5 小时。

### 6.2 课程发布工作流

1. 海报准备好（外部设计师或 Claude 协助生成排版）
2. 跟 Claude 说：「6 月 15 日开课，《紫微斗数入门第三期》，价格 1980，对象 X，大纲 Y」
3. Claude 直接通过 Webflow MCP：
   - 在 Courses Collection 新建条目
   - 上传海报到 Assets
   - 标记 `pinned_to_home = true`
   - 网站 5 分钟内完成更新
4. 同步生成 IG / FB / LinkedIn 课程发布文案，安妍老师人工发布

### 6.3 Live Gallery 更新

- 每场线下活动后：助理/安妍老师拍 5–10 张精选图 → 跟 Claude 说「上传到 gallery，标活动名 X，日期 Y」 → Claude 通过 Webflow MCP 批量上传 + 设置 `pinned_to_home = true`
- 老 gallery 项满 12 张后，最旧的自动取消首页 pin（保留在 Collection 里，但不显示在首页）

### 6.4 是否要上 Zapier / Make 自动化

**短期（前 6 个月）：不上。** 用方案 B 跑通内容流，人工把关社媒措辞。

**中期（6 个月后）：评估是否上。** 如果发布频率达到「每周 ≥ 2 篇文章 + 1 个课程更新」，再考虑接 Zapier / Make 自动化社媒发布。

## 7. SEO 与性能

### 7.1 关键词主题（中文 SEO）

**核心词（高竞争）：**
紫微斗数 / 八字算命 / 风水堪舆 / 取名 / 命理咨询

**长尾词（更易获取流量）：**
- 「紫微斗数怎么看夫妻宫」「八字身弱怎么办」
- 「[城市] 风水大师」「[城市] 命理咨询推荐」
- 「公司取名 五行」「宝宝取名 八字」
- 节气词：「立春 运势」「大暑 注意事项」（节气札记的 SEO 主战场）

**品牌词建立：**
「安妍 命理」「禧安堂」— 通过持续内容产出与社媒回链建立

### 7.2 On-page SEO 必备

- 每页独立 `<title>` 与 `<meta description>`（中英文各一）
- H1 唯一、语义化层级
- 图片 alt 文本中文填写
- Schema.org 结构化数据：`Person`（安妍老师）+ `Article`（文章）+ `Course`（课程）+ `LocalBusiness`（如有线下空间）
- 站点地图 `/sitemap.xml` + `/robots.txt`
- 中英版本 `hreflang` 互链
- 内链策略：服务页 ↔ 相关文章 ↔ 相关课程

### 7.3 性能目标

- LCP < 2.5s（首屏关键内容）
- INP < 200ms（交互响应）
- CLS < 0.1（视觉稳定）
- 图片：Webflow 自动响应式 + WebP；首屏 hero 图 < 200KB
- 字体：标题字体子集化（中文常用字 + 英文）；正文字体走系统字体栈兜底
- JS：Webflow 默认即可；不引入额外重型库

### 7.4 移动端

- 移动优先设计（设计稿先出 375px / 390px，再延展到桌面）
- 底部固定 CTA 栏：WhatsApp + 微信图标
- 触控区域 ≥ 44px
- 所有动效在移动端 50% 强度（动效更轻）

### 7.5 无障碍（A11y）

- 颜色对比度 ≥ 4.5:1（正文）/ 3:1（大字）
- 所有交互元素键盘可达
- 表单标签明确
- 图片必有 alt
- 视频提供字幕
