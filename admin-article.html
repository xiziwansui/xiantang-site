📤 三步发布


            

              
1. 点「📦 下载发布包」按钮

              

                会自动下载两个文件：

                · <slug>.md — 文章本体

                · index.json — 已包含所有现存文章 + 你的新文章
              

              

                ✓ 不用手动编辑 JSON ✓ 不会破坏已发布的文章
              

            


            

              
2. 把两个文件放进 GitHub

              

                打开你的 GitHub repo → 导航到 journal/data/：
              

              
    
                
  • 把 <slug>.md 拖进文件夹（新文件）
    • 
                
  • 用新的 index.json 替换旧的（覆盖）
    • 
                
  • Commit changes
    • 
              

            


            

              
3. 等 Vercel / Netlify 自动部署

              

                通常 1 - 2 分钟。完成后访问 https://xiantang.life/journal.html 就能看到新文章。
              

            


            


            
⚙️ 给 Live Artifact 的接口

            

              你的生成器可以用 postMessage 自动填表：
            

            
window.postMessage({
  type: 'xiantang-article-fill',
  data: { title, slug, category, date,
          glyph, cover, excerpt, body }
}, '*');
